# Medol operations artifacts

Generated by the Medol operations generator for the dev environment. These files describe runtime topology only; they do not provision clusters or execute remote operations.

## Applications

- console (frontend, port 80)
- federation-learning-support (backend, port 8080)
- federation-learning-platform (backend, port 8081)
- federation-learning-runtime-agent (backend, port 8082)

## Infrastructure

- postgres (postgres)
- umadb (umadb)
- axon-server (axon-server, optional/profiled)

## Gateway Routes

- /* -> console
- /api/federation-learning-support/* -> federation-learning-support
- /api/federation-learning-platform/* -> federation-learning-platform
- /api/federation-learning-runtime-agent/* -> federation-learning-runtime-agent

## Flow

```text
CodegenModel
  -> DeploymentModelBuilder
  -> EnvironmentResolver
  -> Docker Compose / Kubernetes / K3s / APISIX renderers
```

## Image Bundle Command

Use `images.mjs` to orchestrate generated backend, frontend, runtime-engine, and infrastructure images from this monorepo:

```bash
node operations/<environment>/images.mjs list
node operations/<environment>/images.mjs all --platform linux/amd64
node operations/<environment>/images.mjs push --prefix registry.example.com/team
node operations/<environment>/images.mjs push-dependencies --prefix registry.example.com/team
node operations/<environment>/images.mjs import
```
