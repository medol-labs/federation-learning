# Harbor operations

Optional Harbor registry operations assets for FederationLearningPlatform (dev).

Harbor is treated as shared operations infrastructure. Keep it separate from application Docker Compose files, then point application image names at the Harbor registry.

## Offline install

1. Download the Harbor offline installer on a connected machine.
2. Copy the installer tarball to this environment.
3. Copy `.env-example` to `.env` and set `HARBOR_INSTALLER`.
4. Run:

```bash
node install-harbor.mjs
```

The script renders `harbor.yml` from `harbor.yml-example`, extracts the official installer, and runs Harbor's `install.sh`. The final `docker-compose.yml` is generated by Harbor itself.

## Application image naming

Use the registry host from this Harbor instance as the generated operations image prefix, for example:

```text
federation-learning-platform-harbor.local/federation-learning-platform/<service>:<tag>
```
