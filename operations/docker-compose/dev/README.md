# Docker Compose Deployment

Generated by the Medol operations generator.

Run the dev topology from this directory:

```bash
cp .env-example .env
docker compose --env-file .env up -d
```

Run Compose from `operations/docker-compose/dev/` so its relative mounts resolve correctly. The APISIX configuration is read from `operations/apisix/dev/`.

APISIX is the primary external entrypoint. Internal services communicate through the `medol-network` Docker network.
