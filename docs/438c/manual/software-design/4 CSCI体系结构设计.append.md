#### 身份访问管理的部署与信任边界

建模中的 PlatformIam 与 ParticipantIam 引用同一套身份访问管理功能定义，但生成到不同部署单元。下表描述部署实例，不代表一份共享的用户数据库。

| 部署单元 | 身份访问管理职责 | 数据与验证方式 |
| --- | --- | --- |
| 联邦学习支持服务 | 承载 PlatformIam 的账户、角色、权限及服务账户令牌管理 | 使用支撑服务本地的身份存储和授权查询 |
| 联邦学习平台服务 | 不部署 IAM 业务上下文；对平台业务接口执行通用认证与授权 | 验证请求携带的令牌或内部服务凭据，不因部署位置自动获得参与方身份数据 |
| 联邦学习运行时代理 | 承载 ParticipantIam，并对参与方本地接口执行认证与授权 | 使用该代理本地的身份存储和授权查询；不与支撑服务或其他代理自动同步 |

平台与运行时代理之间的服务调用依赖部署时配置的令牌和信任参数。共享签名密钥只解决令牌验签，不等于共享用户记录或角色权限；运行时代理对普通用户令牌还会查询本地身份记录。服务账户令牌与内部服务令牌按各自的校验路径处理。当前实现没有 IAM 数据复制链路，部署和测试不得假设平台侧的账户、停用状态或授权变更会自动传播至参与方。
